# garage-story-data

Public, digest-verified OTA schedule dataset for **Garage Story** cars,
motorcycles, and bicycles. Every schedule row carries a permanent `taskId` so
display-copy updates do not break service history, reminders, or snoozes.

RV templates remain binary-bundled until they have a separate digest-backed OTA
release path. See [SCHEMA.md](SCHEMA.md) for the release contract and validation.

Reference only; not professional mechanical advice.
